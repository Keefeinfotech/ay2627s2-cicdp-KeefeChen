2. (60s) Guest mode: add a task + reminder — works fully offline.
3. (45s) Airplane-mode demo: edit/complete tasks offline → reconnect → Sync banner + Sync centre, resolve conflict ("Keep mine").
4. (45s) AI quick-add: "math assignment friday at 5pm #calc" → structured preview → confirm (mock provider labelled).
5. (45s) Groups: create group, invite (hashed, expiring invite code), assign a task.
6. (45s) Admin console + Grafana dashboard (docker compose --profile monitoring) — RBAC, metrics.
7. (60s) Pipeline story: CI green, coverage, Trivy/CodeQL, SonarCloud gate, GitHub release with provenance attestation.
